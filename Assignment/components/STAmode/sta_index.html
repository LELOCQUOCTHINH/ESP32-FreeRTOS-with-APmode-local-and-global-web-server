1. System Overview

Welcome to the Smart Garden Control Panel. This dashboard allows you to monitor environmental conditions and control the irrigation pump.

2. Operating Modes

  • AUTO MODE (Default): The system automatically controls the pump based on sensor readings and your configured settings. Data updates every 10 seconds.
  • MANUAL MODE: You have full control. You can toggle the pump ON/OFF using the "Toggle Pump" button. Data updates every 1 second for real-time feedback.

3. Automation Settings

Click "Auto Mode Settings" to configure thresholds. The system uses AND Logic:

PUMP ON = (Temp Condition) AND (Humidity Condition) AND (Soil Condition)

Example: If you set Soil < 30% and Temp > 25°C, the pump will only turn on when the soil is dry AND it is hot.

4. Connection

You can access this dashboard anytime via http://smartgarden.local as long as your device is on the same WiFi network.

5. Data Safety

Your settings are saved to the device's permanent memory (Flash) and will be restored automatically after a power loss or restart.
